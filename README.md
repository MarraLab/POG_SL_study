# metaGRETTA patient-aligned synthetic-lethality screening

This directory contains the publication-facing workflow used to identify
and screen patient-aligned biallelic loss-of-function (BLOF) contexts
from the POG cohort against DepMap functional-genomic data using GRETTA.

The public workflow begins with **Supplemental Table S1B**, which
contains the POG BLOF alterations used in the analysis. Raw POG
sequencing data, variant calling, copy-number calling, and upstream BLOF
calling are therefore outside the scope of these scripts.

## Workflow

``` text
Supplemental Table S1B
        |
        v
00_generate_cell_line_groups.R
        |
        +-- <group_output_dir>/individual_genes/<gene>/cell_line_groups.csv
                         |
              +----------+----------+
              |                     |
              v                     v
01_KD_screenability.R         03_KO_screens.R
rnai_contexts.R                      |
              |                      +-- identify screenable KO contexts
              v                      +-- run GRETTA KO screens
RNAi_screenable_POG_                 +-- annotate/collect Tier 1/2/3 results
BLOF_contexts.csv
              |
              v
02_KD_screens.R
              |
              +-- run GRETTA RNAi screens
              +-- annotate/collect Tier 1/2/3 results
```

Run the scripts in numerical order for the RNAi workflow
(`00 -> 01 -> 02`). Script 03 uses the grouping files generated by
Script 00 and can be run independently after Script 00 (`00 -> 03`).

## Required software

The scripts are written in R and use:

-   `tidyverse`
-   `GRETTA`
-   `janitor` (Scripts 02 and 03)

Install GRETTA and its required dependencies before running the
workflow. The analysis expects GRETTA-formatted DepMap data compatible
with the study release. https://github.com/ytakemon/GRETTA 

## Required inputs

### 1. Supplemental Table S1B

All four scripts use Supplemental Table S1B as the patient-level
starting point. The expected columns are:

``` text
POG_patient_id
POG_sample_id
POG_sample_disease
BLOF_gene
amino_acid_p
mut_data
```

Only the `BLOF_gene` field is required to define the gene universe for
the downstream DepMap grouping and screening steps, but the scripts
validate the complete publication-table schema.

### 2. GRETTA-formatted DepMap data

Set `gretta_data_dir` to the directory containing the GRETTA-formatted
DepMap data used for the analysis.

The downstream scripts expect, among other GRETTA inputs:

``` text
rnai_long.rda
dep.rda
inferred_MS_status.csv
```

`inferred_MS_status.csv` must contain:

``` text
DepMap_ID
Inferred_MS_status
```

with microsatellite status represented as `inferred_MSS` or
`inferred_MSI`.

### 3. Open Targets tractability annotations

Scripts 02 and 03 require the Open Targets tractability table used for
target annotation. The study used the v23.02 tractability annotations.

Set:

``` r
tractability_file <- "path/to/tractability_v23-02.tsv"
```

to the appropriate local file.

## BLOF cell-line definition

`GRETTA::select_cell_lines()` is used in Script 00 to generate the
standard DepMap alteration groups for each POG BLOF gene.

For this study, BLOF mutant groups are selected according to the
following hierarchy:

1.  **HomDel** is the preferred mutant group.
2.  **T-HetDel** is used only when HomDel is insufficiently represented
    in the final screening context.
3.  **HetDel is never used** as the BLOF mutant group.

A minimum of **3 mutant and 3 control cell lines** is required for a
screen.

The hierarchy is evaluated **after restricting models by assay
availability, disease context, and MSS/MSI status**. HomDel and T-HetDel
models are never pooled simply to reach the minimum sample size.

For example:

``` text
HomDel = 5, T-HetDel = 8  -> HomDel
HomDel = 2, T-HetDel = 8  -> T-HetDel
HomDel = 2, T-HetDel = 2  -> not screenable
HetDel = 20                -> not used
```

## Script 00 --- Generate DepMap cell-line groups

**File:** `00_generate_cell_line_groups.R`

Script 00 extracts the unique POG BLOF genes from Supplemental Table S1B
and runs `GRETTA::select_cell_lines()` for each gene.

Configure:

``` r
supp_table_s1b_file <- "path/to/Supplemental_Table_S1B.csv"
gretta_data_dir <- "path/to/GRETTA_data/23Q4/data"
output_dir <- "path/to/metaGRETTA_screen_output"
```

The main output is:

``` text
<output_dir>/
    individual_genes/
        <gene>/
            cell_line_groups.csv
```

Each `cell_line_groups.csv` must contain:

``` text
DepMap_ID
disease
Group
```

Script 00 also writes:

``` text
DepMap_POG_BLOF_cell_line_group_summary.csv
```

which summarizes the GRETTA groups available for each POG BLOF gene.

Script 00 does **not** decide whether HomDel or T-HetDel will ultimately
be used. That decision is made downstream within each
assay/disease/MSS-MSI context.

## Script 01 --- Identify screenable RNAi contexts

**File:** `01_identify_screenable_rnai_contexts_FIXED(1).R`

Script 01 determines which POG BLOF contexts can be screened using the
RNAi dependency data.

Configure:

``` r
supp_table_s1b_file <- "path/to/Supplemental_Table_S1B.csv"
gretta_data_dir <- "path/to/GRETTA_data/23Q4/data"

# Must point to the individual_genes directory generated by Script 00.
lof_context_dir <- "path/to/metaGRETTA_screen_output/individual_genes"

output_dir <- "results/rnai"
min_group_size <- 3L
```

For each POG BLOF gene, the script evaluates disease contexts returned
by GRETTA, plus a pan-cancer (`pancan`) context, separately in MSS and
MSI models.

Only cell lines with RNAi data and a known MSS/MSI assignment are
eligible.

The output is:

``` text
results/rnai/RNAi_screenable_POG_BLOF_contexts.csv
```

The table contains:

``` text
GeneName
mut_group
disease
MS_status
n_control
n_homdel
n_thet_del
n_mutant
is_screenable
```

`mut_group` records the group selected by the HomDel -\> T-HetDel
hierarchy.

## Script 02 --- Run RNAi synthetic-lethality screens

**File:** `02_KD_screens_FINAL.R`

Script 02 reads the screenable contexts generated by Script 01 and runs
the corresponding GRETTA RNAi synthetic-lethality screens.

Configure the same S1B, GRETTA-data, grouping, and RNAi output paths
used in Scripts 00/01:

``` r
supp_table_s1b_file <- "path/to/Supplemental_Table_S1B.csv"
gretta_data_dir <- "path/to/GRETTA_data/23Q4/data"
lof_context_dir <- "path/to/metaGRETTA_screen_output/individual_genes"
tractability_file <- "path/to/tractability_v23-02.tsv"

# Must match the output_dir used in Script 01.
output_dir <- "results/rnai"
```

Analysis parameters are configurable:

``` r
min_group_size <- 3L
n_perm <- 10000L
core_num <- 8L
make_plots <- TRUE
```

Script 02 validates that the mutant group supplied by Script 01 is
either `HomDel` or `T-HetDel`, reconstructs the corresponding
mutant/control cell-line IDs, and requires at least three models in each
group before screening.

RNAi screens are performed separately in MSS and MSI models. The script
runs `GRETTA::GI_screen()`, permutation testing with
`GRETTA::GI_screen_perms()`, and appends permutation-derived p-values
before applying the study's RNAi tier criteria.

Major outputs include:

``` text
results/rnai/
    intermediate_files/
    GI_results/
    GI_plots/
    RNAi_POG_BLOF_screen_results_Tier123.csv
```

Plot generation can be disabled with:

``` r
make_plots <- FALSE
```

## Script 03 --- Run CRISPR KO synthetic-lethality screens

**File:** `03_KO_screens_FINAL.R`

Script 03 performs both the screenability assessment and GRETTA CRISPR
knockout screening. It uses the cell-line grouping files generated by
Script 00 but does not depend on Scripts 01 or 02.

Configure:

``` r
supp_table_s1b_file <- "path/to/Supplemental_Table_S1B.csv"
gretta_data_dir <- "path/to/GRETTA_data/23Q4/data"

# Must point to the individual_genes directory generated by Script 00.
lof_context_dir <- "path/to/metaGRETTA_screen_output/individual_genes"

tractability_file <- "path/to/tractability_v23-02.tsv"
output_dir <- "results/ko"
```

Analysis parameters are configurable:

``` r
min_group_size <- 3
n_perm <- 10000
core_num <- 12
make_plots <- TRUE
```

The workflow is run separately for MSS and MSI cell lines. Within each
subset, Script 03:

1.  restricts models to those with CRISPR dependency data;
2.  identifies screenable disease and pan-cancer contexts;
3.  applies the HomDel -\> T-HetDel hierarchy;
4.  runs `GRETTA::GI_screen()` and `GRETTA::GI_screen_perms()`;
5.  applies the study's CRISPR KO tier criteria; and
6.  collects Tier 1/2/3 candidates.

Major outputs include:

``` text
results/ko/
    KO_screenable_POG_BLOF_contexts_MSS.csv
    KO_screenable_POG_BLOF_contexts_MSI.csv
    KO_POG_BLOF_MSS_screen_results_Tier123.csv
    KO_POG_BLOF_MSI_screen_results_Tier123.csv
    KO_POG_BLOF_MSS_MSI_screen_results_Tier123.csv

    individual_genes/
        <gene>/
            intermediate_files/
            GI_results/
            GI_plots/
```

The `results/ko/individual_genes/` directory contains **screen
results**, whereas the `lof_context_dir` contains the **cell-line
grouping inputs generated by Script 00**.

## Running the workflow

From the project root:

``` bash
Rscript scripts/00_generate_cell_line_groups.R
Rscript scripts/01_identify_screenable_rnai_contexts.R
Rscript scripts/02_KD_screens.R
Rscript scripts/03_KO_screens.R
```

Before running, edit the user-defined path section at the top of each
script.

For RNAi, **Script 01 must be completed before Script 02**, because
Script 02 reads `RNAi_screenable_POG_BLOF_contexts.csv` generated by
Script 01.

Script 03 can be run after Script 00 independently of the RNAi workflow.

## Re-running analyses

Script 00 reuses an existing `cell_line_groups.csv` when one is already
present.

Scripts 02 and 03 skip completed screen results when the expected final
result file already exists. This allows interrupted analyses to be
resumed without rerunning every completed screen.

If the cell-line grouping logic, input data, microsatellite-status
assignments, or screening definitions are changed, use a clean output
directory or remove stale outputs before rerunning so that previously
generated files are not inadvertently reused.

## Reproducibility notes

The scripts separate three concepts that should not be conflated:

-   **Patient BLOF definition:** supplied by Supplemental Table S1B.
-   **DepMap cell-line alteration groups:** assigned by
    `GRETTA::select_cell_lines()`.
-   **Screenability:** determined after restricting the DepMap models by
    assay, disease context, and MSS/MSI status.

Consequently, the presence of a POG BLOF gene in Supplemental Table S1B
does not imply that a functional-genomic screen can be performed. A
context is screened only when the required mutant and control models are
available under the study criteria.

The screenability tables retain the numbers of available HomDel and
T-HetDel models so that the selected mutant group can be audited.

## Output interpretation

The resulting Tier 1/2/3 tables contain **candidate synthetic-lethal
interactions generated from functional-genomic screening**. These
results are intended as hypothesis-generating research outputs and
should not be interpreted as clinical treatment recommendations.

For the exact statistical thresholds, effect-size definitions,
tractability grouping, and priority-class definitions used in the
analysis, refer to the corresponding functions in Scripts 02 and 03 and
to the Methods section of the manuscript.
